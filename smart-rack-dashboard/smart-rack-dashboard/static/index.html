실행 전 필수 조건

조건을 하나라도 충족하지 못하면 재투입을 차단합니다.

  • PC 연결 및 SSD 인식 정상
  • 장비 예약 유효 · Port 점유 없음
  • 담당자가 환경성 불량으로 검토 완료
  • 원본 Log / Dump 보존 확인
  • 횟수 제한 및 재투입 간격 충족
  • 자동 실행은 Port별 허용과 신뢰도 조건 추가
자동 OFF는 신규 자동 등록을 중지합니다.
